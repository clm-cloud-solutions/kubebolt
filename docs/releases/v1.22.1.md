# KubeBolt 1.22.1 — security patch

1.22.1 is a **security patch** over 1.22.0 — no feature changes. It clears the
vulnerabilities ArtifactHub flags on the published images. Drop-in over 1.22.0 —
no schema change, no migration. The node agent bumps to **1.3.1**.

## Fixes

- **API image rebuilt on Go 1.25.12** (was 1.25.11) — clears the Go stdlib
  **CVE-2026-39822** (HIGH) and **CVE-2026-42505** (MEDIUM). The agent's builder was
  already 1.25.12.
- **`golang.org/x/net` → 0.56.0** and **`golang.org/x/text` → 0.39.0** across the
  API and agent — clears **CVE-2026-46600** (x/net) and **CVE-2026-56852** (x/text).
- **VictoriaMetrics pinned to `v1.148.0-scratch`** (was `v1.147.0-scratch`) — a
  Go-1.26.5+ build that clears the same stdlib CVEs in the embedded metrics store,
  and lets the two now-unnecessary `.trivyignore` suppressions be removed. The
  vmagent sidecar tracks it in lockstep.

`golang.org/x/crypto` GO-2026-5932 has no upstream fix yet and is left as-is
(Unknown severity, non-gating).

## Upgrading

```bash
helm upgrade kubebolt oci://ghcr.io/clm-cloud-solutions/kubebolt/helm/kubebolt --version 1.22.1
helm upgrade kubebolt-agent oci://ghcr.io/clm-cloud-solutions/kubebolt/helm/kubebolt-agent --version 1.3.1
```
