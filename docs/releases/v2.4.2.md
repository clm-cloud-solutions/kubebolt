# KubeBolt 2.4.2 — security rebuild

Drop-in over 2.4.1. No schema change, no migration, no new setting. The agent
moves to **1.4.5**, also a security rebuild with the same code and metric
schema.

Advisories published after 2.4.1 reached its base images and Go: Artifact Hub
rated the 2.4.1 images D. Every image is rebuilt on current bases. Findings
**with a fix available**, scanned with Trivy 0.76.1:

| Image | 2.4.1 / agent 1.4.4 | 2.4.2 / agent 1.4.5 |
|---|---|---|
| api | 1 HIGH, 1 MEDIUM, 2 UNKNOWN | none |
| web | 17 HIGH, 24 MEDIUM, 4 LOW, 6 UNKNOWN | none |
| agent | 1 HIGH, 3 MEDIUM, 3 UNKNOWN | none |
| VictoriaMetrics v1.154.0 (bundled) | 1 HIGH | 1 HIGH, waived until v1.155.0 — see below |

## What changed

- **Go 1.26.9 → 1.26.10** on every build path: the api and agent images, the
  single-container image and the cross-compiled binaries. Fixes
  CVE-2026-111943 (crypto/x509, HIGH).
- **api image:** Alpine 3.21 → 3.24. Alpine 3.21 leaves support on
  2026-11-01. chi 5.2.5 → 5.4.0 fixes CVE-2026-114437, in a middleware
  KubeBolt does not use.
- **web image:** nginx 1.27 on Alpine 3.21 → nginx 1.30 on Alpine 3.24. The
  1.27 images are no longer rebuilt; this is where the curl, pcre2, expat and
  brotli findings came from.
- **single-container image:** Alpine 3.22 → 3.24.

## Agent 1.4.5

Same code and the same v1.0 metric/label schema as 1.4.4.

- Go 1.26.10 (CVE-2026-111943).
- cilium 1.19.3 → 1.19.5: three MEDIUM advisories.
- Base image distroless `static-debian12` → `static-debian13`. The Debian 12
  fixes for ca-certificates and tzdata no longer reach the debian12 image. The
  user is still `65532:65532`, so OpenShift and `runAsNonRoot` setups need no
  change.

## What remains

- **VictoriaMetrics v1.154.0**, the bundled metrics store, and the agent
  chart's optional vmagent (`scrape.enabled=true`). The vendor's binary is
  built on Go 1.27.2 and carries CVE-2026-111943. No stable release has the
  fix yet; only v1.155.0-rc0 does, and a release candidate does not ship. The
  CVE is waived in `.trivyignore-thirdparty` until 2026-11-09. In KubeBolt it
  is reachable only on VictoriaMetrics' outbound TLS; the bundled path is
  in-cluster plaintext. The next release moves to v1.155.0.
- **GO-2026-5932**, in the api and agent binaries, flags
  `golang.org/x/crypto/openpgp` as unmaintained. KubeBolt does not use that
  package, and no version of `x/crypto` fixes it, so it stays listed under
  "All" and not under "Fixable".

## Upgrading

```bash
helm upgrade kubebolt oci://ghcr.io/clm-cloud-solutions/kubebolt/helm/kubebolt --version 2.4.2
helm upgrade kubebolt-agent oci://ghcr.io/clm-cloud-solutions/kubebolt/helm/kubebolt-agent --version 1.4.5
```

Do not use `--reuse-values` across chart versions; pass your values file
(`-f`) or `--reset-then-reuse-values`.
