## 1. The external dependency, read from its address

When there is no Service fronting a dependency at all, it may be wired as a raw
URL or IP in the failing workload's own config — an env var or an argument. There
is no Service or Endpoints to inspect and the namespace legitimately has zero of
that workload, and Kobi used to conclude it was missing and must be created here.
The prompt now tells it to read the workload's YAML, find the target in its
env/args and classify it the same way it classifies any address: an IP that is
neither a listed node's InternalIP nor inside a node's pod CIDR is external, a
hostname in the cluster domain is in-cluster, any other FQDN is external. A
dependency's locality is decided by its address, not by whether a Service fronts
it — and the fix is to restore or repoint that endpoint, never to create a
workload in this cluster.

## 2. The OpenAI fallback leaked `<tool_call>` into answers

Kobi's primary provider is Claude, which emits tool calls natively. The
OpenAI-compatible fallback also serves prompted-tool-calling reasoning models
(Qwen, DeepSeek-R1) which emit `<tool_call>{json}</tool_call>` *inside* the
message content as well as in the native `tool_calls` field, and the adapter
took the content verbatim. `stripToolCallTags` now removes those blocks (and a
dangling opener from a truncated stream) before the text becomes visible; native
tool calls are still read separately, so nothing is lost. Covered by
`TestStripToolCallTags`.

## 3. A path back to account administration

Inside a cluster the sidebar deliberately hides the Administration section (it
keeps identity, agents, AI and system out of the same menu as Pods). The way
back was to press **Fleet** in the topbar — which names your clusters, not your
account. Two entries now lead to the first administration hub the signed-in user
may open (`useAdminLanding`): the avatar menu, and a single "Administration"
link in the sidebar footer inside a cluster, next to Feedback and About.
Navigating there does not change the active cluster, so you come back where you
were.
