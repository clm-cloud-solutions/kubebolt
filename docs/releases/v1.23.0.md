# KubeBolt 1.23.0 — the Kobi rebrand, dashboard & admin polish, and the Claude 5 model family

1.23.0 folds in the shared UI/UX work homologated from KubeBolt EE 1.23 —
the **Kobi chat rebrand**, a round of **dashboard and admin polish**, and the
**Claude 5** model family in the Copilot catalog — plus a Cost-chart fix. The
version number stays **aligned with EE** (EE ships as `1.23.0-e1`), so the two
lines keep tracking together.

Drop-in over 1.22.1 — **no schema change, no migration**. The node agent is
unchanged (stays **1.3.1**).

---

## AI Copilot (Kobi) — chat rebrand, Claude 5, message legibility — *(EE 1.23)*

The Copilot chat surface is rebranded to the **"Solo Kobi"** identity — warm
black, electric green `#00e07a` as an accent (never a fill), thin bevels — with
message-legibility fixes throughout. The change is **scoped to Kobi surfaces**;
the global app theme is untouched.

- **Panel, toggle, Ask buttons, sigil** move onto Kobi-scoped `--kobi-*` tokens
  (light is translated to the app's cool family, code blocks stay dark in both
  themes), the AI-family bezel/shimmer recolors to monochrome green, and the
  floating panel gets a lifted shadow.
- **Markdown renderer**: 15px body with tighter heading scale, themed code
  colors, a light yaml/bash line highlighter, and readable table headers.
- **Proposal / tool cards** move to Kobi status tokens; low-risk proposals get a
  faint wash so they no longer twin with the user bubble; risk is clamped so
  deletes / irreversible actions always read high.
- **Space Grotesk** display font for Kobi headings; tooltips flip at the
  viewport edge instead of clipping.

**Claude 5 model family** lands in the model catalog + pricing: **Opus 5**,
**Sonnet 5**, **Fable 5**, and **Opus 4.8**, surfaced first as "Claude 5
(current)"; the default Anthropic model moves to `claude-sonnet-5`, and the
1M-token context window is recognized for the new tier.

## Dashboard & admin polish — *(EE 1.23, shared)*

- **Sidebar**: the collapsed rail "peeks" open on hover as a floating overlay,
  the Clusters item shows a live count, and per-group collapse works in rail
  mode.
- **Logs**: auto-refresh is now an opt-in **"Live" toggle** (default off), so
  reading a filtered/scrolled log isn't yanked out from under you every 10s.
- **Overview**: Completed (Succeeded) Job pods get their own row and count
  toward the health ring — a batch of finished Jobs no longer drops the gauge;
  the health headline stays positive when the cluster is healthy.
- **Ingest activity**: the samples/sec headline no longer reads "—" for a
  single-path tenant, a per-tenant rate-limit line and an **active-series
  by-cluster** breakdown land, and the gRPC chips read "opened/closed".
- **Add-cluster wizard** wires the **OpenCost mode picker** (bundled / scrape /
  read-from-Prometheus) and emits the matching Helm flags.
- **Range selector** gains **14d / 30d** history windows.
- **Clusters page**: agent-proxy clusters show a **Live / Offline** badge, and
  their display name carries a **"(via agent)"** marker.
- **Copilot usage**: the session modal resolves the raw agent-proxy context to
  the friendly cluster name.
- Theme-aware autofill styling + a proper disabled state for the primary button.

## Fixes

- **Cost — "Allocated vs total cost" chart**: the range query errored with
  *"duplicate time series on the right side of `* on(node) group_left`"*
  whenever OpenCost restarted inside the window (VM keeps the stale + fresh
  `node_*_hourly_cost` series). Both `group_left` joins now wrap the right side
  in `max by (node) (…)`, so each node collapses to one cost series.

## Upgrading

Drop-in over 1.22.1 — no schema change, no migration. The agent stays 1.3.1.

```bash
helm upgrade kubebolt oci://ghcr.io/clm-cloud-solutions/kubebolt/helm/kubebolt --version 1.23.0
```

The Kobi rebrand and dashboard polish are pure frontend — they apply on the
next page load with no configuration.
