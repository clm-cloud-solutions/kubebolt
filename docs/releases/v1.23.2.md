# KubeBolt 1.23.2 — closing the 1.23 line: one Go toolchain, scan waivers for the bundled VictoriaMetrics, and what already landed on `main`

1.23.2 is a **maintenance release** that closes the 1.23 line before OSS starts
tracking KubeBolt EE 2.x **release by release** (2.0.0, 2.0.1, … 2.1.0 — each
with a version map like the one below). Drop-in over 1.23.1 — **no schema change,
no migration**. The node agent is **1.4.0** (released 2026-09-01 on its own cadence;
strongly recommended on every install, see below).

## Already on `main` / `develop` since 1.23.1 — ships here

- **Cluster Map progressive disclosure** (2026-08-06, homologated from EE's map
  batch that shipped in 2.0.0-e2): collapsible namespaces with "Collapse all / Expand
  all / Tidy", free-position drag in collapse mode with expand-reflow, **focus mode**
  (select a resource → 1-hop neighbourhood spotlighted, rest dimmed), a selectable
  Traffic flow window (1m/2m/5m/10m) with a stale-vs-absent empty state, and a
  full-bleed canvas on `/map`.
- **Kobi Copilot pricing** (PR #181, from EE 2.0.0-e2): Sonnet 5 at its permanent
  $2 / $10 rate, plus **GPT-5.6** in three variants (sol / terra / luna).
- **Brand** (PR #178): the Kobi sigil's resting and watching states carry the brand
  green in both themes — the first slice of the Split Bolt brand; the logo, favicons
  and app accent arrive with 2.0.3.
- **OpenShift guide** (PR #179, OSS-own): `docs/guides/openshift.md`, the
  `restricted-v2` web workaround and the in-cluster Events timeout.
- **Incident-scenario demo manifests** (PR #180, OSS-own): `deploy/test/incident-scenarios.yaml`.
- **`golang.org/x/crypto` 0.55.0** (CVE-2026-56854) and the api image on
  `golang:1.26.6-alpine` (2026-09-01).
- **Agent 1.4.0** (`agent-v1.4.0`, 2026-09-01): `dropNetworkInterfaces` prefix-matches
  entries ending in `*`, and the defaults cover the cloud-CNI veth peers
  (`azv*` / `veth*` / `eni*` / `cali*`) plus `lo`. Measured on a 2,183-pod AKS
  cluster those were ~85 % of all active series. See `packages/agent/CHANGELOG.md`.

## Security and toolchain

- **One Go toolchain: 1.26.6.** The api image had already moved to
  `golang:1.26.6-alpine`, but `go.mod` (×3), `ci.yml`, `codeql.yml` and the
  `build-binaries` job in `release.yml` were still on the 1.25 line — so the
  **krew / Homebrew binaries and the single-container image** still carried the
  2026-08 stdlib wave: **CVE-2026-33818** (encoding/asn1), **CVE-2026-56853**
  (net/http, unencrypted HTTP/2), **CVE-2026-56858** (html/template XSS),
  **CVE-2026-56859** (encoding/xml), **CVE-2026-56860** (net/url),
  **CVE-2026-56862** (crypto/tls) — all HIGH, all fixed in 1.25.13 / 1.26.6. Every
  build path now pins 1.26.6.
- **`golang.org/x/mod` 0.40.0** (CVE-2026-56864 / CVE-2026-56865, HIGH — a malicious
  GOSUMDB could serve arbitrary module content; `sumdb/tlog`) and
  **`google.golang.org/grpc` 1.83.1** (CVE-2026-84304, HIGH). Both are linked into
  the api binary, so the release `image-scan` gate would have rejected 1.23.2 with
  the images already pushed; bumped in the api, proto and agent modules in lockstep.
  The **published agent image 1.4.0** was built with gRPC 1.82.1 and is not rebuilt
  by this release — an agent 1.4.1 on the agent's own cadence is the fix.
- **Bundled VictoriaMetrics / vmagent waivers.** The `v1.148.0-scratch` binaries are
  built by upstream on Go 1.26.5 and carry eight HIGH stdlib CVEs that no published VM
  build fixes yet (`v1.149.0-scratch` is built the same way). They are waived in
  `.trivyignore` with owner, justification and a **remove-by of 2026-09-15**, so the
  release preflight scan can distinguish "we cannot rebuild a vendor binary" from
  "we forgot to bump a dependency we compile". Exposure is bounded: VM runs
  in-cluster and its HTTP surface is reachable only from the KubeBolt API over the
  pod network, never through the ingress. Mitigation, not a fix; the pin moves the
  day upstream ships a Go 1.26.6+ build.

## Not in OSS (EE-only) — from 1.23.2-e1 … 1.23.4-e1

Kobi Autopilot: `blockedNamespaces` enforcement, the circuit breaker that could latch
shut, transport failures classified ahead of parse failures, per-stage LLM timeouts
and the platform provider endpoint, the paginated incident list, the `humanApproved`
query loop, and the `brace-expansion` CVE pin in the Autopilot image. Autopilot is
part of KubeBolt EE.

## Upgrading

```bash
helm upgrade kubebolt oci://ghcr.io/clm-cloud-solutions/kubebolt/helm/kubebolt --version 1.23.2
helm upgrade kubebolt-agent oci://ghcr.io/clm-cloud-solutions/kubebolt/helm/kubebolt-agent --version 1.4.0
```

No values change, no schema change, no migration. The agent bump is optional but
recommended: on cloud CNIs it removes most of the per-pod veth series at the source.
As always, prefer explicit `-f values.yaml` over `--reuse-values` so a renamed key
never silently keeps an old value.
